# Cinema Geral Decisions

> **Fonte canônica:** [[37-regras-e-decisoes/37.06-regras-de-producao]]
> Carregue essa nota para regras detalhadas, exceções e exemplos.

## Regras

### FORMA vs CONTEÚDO (Bordwell)
A forma não é embalagem — é parte do significado.

### DECUPAGEM
Quebrar cena em planos (mestre, médio, close, inserts).

### MONTAGEM INTELECTUAL (Eisenstein)
A + B = C (significado novo que não existe em A ou B).

### 4 TIPOS DE MONTAGEM (Eisenstein)
Métrica, Rítmica, Tonal, Overtonal.

### CINEMA NÃO É TEATRO FILMADO (Bresson)
Cinema puro = imagem + som + tempo.

### PRODUÇÃO INDEPENDENTE (Ferreira)
Orçamento limita, não impede.

## Anti-Patterns
- Nunca filmar sem decupagem prévia.
- Nunca esquecer que cinema é técnica + arte + indústria.
