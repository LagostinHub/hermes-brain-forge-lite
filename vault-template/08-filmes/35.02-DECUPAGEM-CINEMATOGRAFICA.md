# Decupagem Cinematográfica — Cliente C v6

## Regra da escala (teoria aplicada)

Do material `film-decupage`: "Wide plus large equals agency; wide plus small equals insignificance". A majestade do Cliente C é construída na relação do humano com o vasto (água, cidade, cardume).

### Escada de escalas (rebalanceada v6)

| Escala | Quantidade | Função no filme |
|---|---|---|
| EWS (Extreme Wide) | 3-4 takes | Establishing majestoso: cardume, cidade, oceano profundo |
| WS (Wide) | 3-4 takes | Relação corpo-água, descida, profundidade |
| MS (Medium) | 5-6 takes | Diálogo interno, observação, decisão |
| MCU/CU | 4-5 takes | Picos emocionais: olhos abrindo, sorriso, mão no botão |
| ECU | 2 takes | Detalhes temporais: relógio 23:47→23:48 |

**Ritmo geral:** cenas de escritório = fragmentadas (cortes rápidos). Cenas de água = contemplativas (takes longos, poucos cortes).

## Ato I — O Escritório (Cena 01)

### Cenário

| Elemento | Definição |
|---|---|
| **Espaço** | Grande, executivo, janela piso-a-teto para cidade acesa |
| **Mesa** | Vidro/metal clean, laptop fechado, copo d'água |
| **Escultura** | Abstrata, **laranja #FD5A23**, formato cliente-c de pesca. Única cor da cena. Discreta. |
| **Relógio** | Grande analógico clássico, preto com dourado |
| **Cadeira** | Couro preto presidente |
| **Paredes** | Estantes com livros padrão, sem vida pessoal |
| **Luz** | Escura. Só 3 fontes: laranja da escultura, tela do computador, cidade lá fora |
| **Tom** | Racional, organizado, previsível, sem vida |

### Decupagem: 3 takes, 3 cortes, 8 segundos

```
T1 (2.5s)        T2 (2.5s)        T3 (3s)
ECU relógio      ECU relógio      MS executivo
23:47            23:48            perfil 3/4 + cidade
LOCKED           LOCKED           push-in + olhos fecham
TIC.TAC          TAC + drone      respiração
```

### Contraste de ritmo

- **T1 → T2:** Idêntico (só ponteiro muda) = repetição perturbadora
- **T2 → T3:** Abre pro mundo = revelação (cidade, escultura, executivo)
- **Som:** TIC.TAC → drone → respiração (escritório some, ser humano aparece)

### SC06 — Profundidade (7s, 2 takes)

| Take | Escala | Frame | Mov. | Duração |
|---|---|---|---|---|
| 1 | **MS** | Mergulhador profundo, olhos fechados | Locked | 3.5s |

## Princípios de direção

1. **Ritmo:** Fragmentado no escritório → contemplativo na água → fragmentado na volta
2. **Cor:** Petróleo + laranja (escritório) → teal/azul bioluminescente (água) → petróleo + laranja (volta)
3. **Som:** TIC.TAC mecânico → silêncio aquático → respiração humana
4. **Movimento:** Locked/tensão → fluxo/contração → locked/libertação
5. **Escala:** Fragmentada no escritório (ECU/CU) → majestosa na água (EWS/WS) → íntima na volta (MS/CU)
