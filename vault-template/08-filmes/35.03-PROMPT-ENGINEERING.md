## O erro do V4 (o que quebrou)

1. **KSampler com cfg 3.5** — FLUX usa cfg ~1.0. 3.5 satura, plástifica
2. **Removi DetailDaemon** por erro de nome — perdeu textura de pele
3. **Reescrevi prompts do zero** — joguei fora a tabela de 9 luzes e a decupagem do board
4. **Usei "cinematic"** — palavra proibida que retorna média de tudo
5. **Prompt terminava com "no wetsuit"** — contradição literal que gerou peito nu

## A receita que funciona (V3 → V6)

- **SamplerCustom + cfg 1.0** (não KSampler)
- **DetailDaemon 0.6 + start 0.2/end 0.8**
- **LoRA realismo 0.85**
- **FluxGuidance 3.5** para condicional
- **Seed derivada do d2** (9011 + cena×10 + take)
- **9-slot architecture** (escala → posição → material → luz → d2 → roupa → neg → open gate → formato)

## Regras do lexicon (o que funciona vs o que não)

| Funciona | Não funciona |
|---|---|
| "35mm film stock" | "cinematic" |
| "f/2.8, T2.8" | "cinematic composition" |
| "Kodak Vision3 500T" | "shot on Arri Alexa" |
| "teal petroleum shadows" | "dark cinematic mood" |
| "one-tenth of frame height" | "wide cinematic shot" |
| "deep transparent shadows" | "beautiful cinematic lighting" |

A regra: **material + número = controle**; **adjetivo = perda de controle**.

## Arquitetura 9-slot (o template)

Cada prompt segue a ordem (slots iniciais dominam):

1. Escala + proporção (ex: "EWS, one-tenth")
2. Posição + olhar (ex: "lower-left third, gaze off edge")
3. Material + iluminação (ex: "35mm stock, teal shadows")
4. Luz cena (ex: "god rays from ABOVE")
5. d2 verbatim
6. Roupa (ex: "neoprene wetsuit")
7. Negativas (ex: "no plastic, off-lens")
8. Open gate 56% (ex: "56% central frame")
9. Formato (ex: "1:1")

## O conceito de open gate

O conteúdo essencial vive no quadrado central. As margens são atmosfera. Isso permite:
- Crop 16:9: corta topo/baixo (margens de água) → sujeito preservado
- Crop 9:16: corta lados (margens de luz) → sujeito preservado
- Master 1:1: tudo visível, máximo contexto

Não interpolamos. Zero stretching. A decisão de enquadramento está na geração, não no pós.
