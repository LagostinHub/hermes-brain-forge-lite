## Como usar (agentes)

**Busca semântica (tool MCP `search`):**
```
mcp__obsidian_kb__search { query: "termo por significado", top: 5 }
```
- Hybrid: BM25 (palavra) + vetor (significado) + graph (notas ligadas via wikilinks)
- Retorna: título, path relativo, snippet, linhas, tags
- Filtros: `tags: [...]`, `properties: ["KEY=VALUE"]`, `mode: bm25|vector|hybrid`

**Sempre ANTES de abrir arquivos** — 1 busca substitui 10 greps.

## Como subir

```bash
# destacado (sobrevive ao Hermes)
"%OBSIDIAN_VAULT_PATH%\.obsidian-kb\start-okb.cmd"

# foreground (debug)
"%USERPROFILE%\AppData\Local\hermes\hermes-agent\venv\Scripts\obsidian-kb.exe" serve --config "C:/AI/[DONO]_VAULT/.obsidian-kb.toml" --vault "C:/AI/[DONO]_VAULT" --port 8766
```

## Reindexar (após mudanças estruturais no vault)

```bash
"%USERPROFILE%\AppData\Local\hermes\hermes-agent\venv\Scripts\obsidian-kb.exe" index --vault "C:/AI/[DONO]_VAULT" --config "C:/AI/[DONO]_VAULT/.obsidian-kb.toml"
```
- Incremental (só reprocessa mudanças). Full rebuild: adicionar `--rebuild` (demora ~10 min com embeddings).
- **Rotina sugerida:** reindexar no Weekly Review, ou após ingerir lote grande de notas.

## Pitfalls

1. **Serve morre se for filho de sessão do Hermes** — sempre subir via `start-okb.cmd` ou Startup, nunca `&` num terminal de agente.
2. **MCP não re-registra em sessão viva** — se o serve cair e voltar no meio da sessão, a tool só volta na próxima sessão. Protocolo continua funcional via HTTP direto (`/search`, `/mcp`).
3. **Busca retorna 0 se o índice tá vazio/incompleto** — verificar com `obsidian-kb stats --vault ...` (deve mostrar ~884 notes).
4. **Plugin Obsidian**: campo "obsidian-kb binary" deve apontar pro caminho absoluto do .exe (default `obsidian-kb` não resolve no Windows).
5. **Porta 8766** — se mudar, atualizar: config.yaml (Hermes), opencode.json (OpenCode), start-okb.cmd, okb-watchdog.vbs.
