# Skills.sh — Marketplace de Skills

> Fonte canônica de skills de terceiros para o ecossistema Hermes.
> CLI: vercel-labs/skills (npm global).

## Como usar

```bash
# Pesquisar skills
npx skills search <query>

# Ver skills de um repo específico
npx skills add <owner/repo> --agent hermes-agent -l

# Instalar skills (com cuidado!)
npx skills add <owner/repo> --agent hermes-agent --copy -y

# Listar skills instaladas
npx skills list -g
```

Atalhos:
- `--copy` em vez de `--symlink` (instala arquivos no caminho nativo em vez de links)
- `--agent hermes-agent` restringe a apenas ao Hermes

## ATENÇÃO: spread automático

A CLI `npx skills add` por default expande em **75** pastas no cwd! Quando executar no `[CAMINHO]`, cria pastas `~/.claude/skills`, `~/.codex/skills`, `~/.devin/skills`, `~/.grok/skills`, etc — uma para cada agente detectado.

**SEMPRE LIMPAR** após use:

```powershell
# Remove todas as pastas de agente (exceto .agents) criadas por npx skills
$plane = "[CAMINHO]"
Get-ChildItem $plane -Directory -Force | Where-Object { $_.Name -match "^\." -and $_.Name -ne ".agents" -and (Test-Path "$($_.FullName)\skills") } | Remove-Item -Recurse -Force
```

Alternativa: copiar manualmente da CLI-cache após install para `~/.agents/skills/` (mais seguro).
