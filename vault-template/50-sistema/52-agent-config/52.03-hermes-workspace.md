# Hermes Workspace — Swarm Multi-Agent

> Projeto completo do ecossistema Hermes (outsourc-e/hermes-workspace v2.3.0)
> Repo: https://github.com/outsourc-e/hermes-workspace.git
> Setup local: %USERPROFILE%\hermes-workspace\

## O que é

- Aplicação Electron desktop (chat, files, memory, skills, terminal)
- Sistema swarm multi-agente com 10 workers especializados
- Companion app do Hermes Agent v0.15+

## Os 10 Workers (swarm.yaml)

Ver `swarm.yaml` no repo para definições completas. Cada worker tem:

- Profile ID
- **Memória semântica:** [FERRAMENTA] (MCP) para recuperação semântica entre sessões.
- Wrapper em `~/.local/bin/<worker>:<mode>`
- Greenlight rules (ações que requerem aprovação humana)

| Worker | Função |
|---|---|
| orchestrator | Roteamento de missões, decomposição, greenlight gate |
| km-agent | RAZSOC, GBrain knowledge steward |
| builder | Implementação escopada, testes, diff pequeno |
| reviewer | Security review, regression detection, merge gate |
| qa | Browser workflow smoke tests |
| researcher | GBrain-first research, bounded autoresearch |
| ops-watch | Gateway/cron/MCP health, lifecycle sweep |
| maintainer | Upstream dependencies, patch hygiene |
| strategist | Wedges, bets, kill criteria |
| inbox-triage | Capture, discard, route, defer filter |

## Como rodar (não foi testado ainda)

Pré-requisitos: tmux, Node 22+, pnpm.

```powershell
cd %USERPROFILE%\hermes-workspace
pnpm install
pnpm dev
```

Isto sobe o Electron UI em http://localhost:3000 (com fallback :3002).

## Relação com Hermes Agent (puro)

Hermes Agent puro (este que está rodando) E diferente do Hermes Workspace (UI Electron).
- Hermes Agent: CLI + skills + gateway
- Hermes Workspace: UI Electron para Hermes Agent + sistema swarm
- Hermes Studio: GUI bundled, terceira opção de UI (mais leve que Workspace)

Vocês dois (Hermes Agent + Hermes Workspace) compartilham o mesmo gateway (`AppData\Local\hermes\`).
