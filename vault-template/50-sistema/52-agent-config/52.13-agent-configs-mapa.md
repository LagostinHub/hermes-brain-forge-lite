# Agent Configs Mapa

Onde vive cada config do sistema de agentes (censo 2026-09-02, verificado em disco). Complementa 52.11-skills-mapa (skills) e [[52.01-hermes-agent]]. Distribuição: [REPO].

## Resposta estrutural (forge)

O repo `[REPO]` é **uma pasta só**, mas o instalador **espalha** cada config para o seu local canônico na máquina — igual à disposição atual:

| Template no repo | Destino no install (Windows) |
|---|---|
| `configs/opencode.json` | pasta home do OpenCode (`[CAMINHO]`) |
| `configs/hermes/config.yaml` + `.env` | `%LOCALAPPDATA%\hermes\` |
| `vault-template/.obsidian/*` | dentro do vault instalado |
| `skills/*` (4 árvores) | `%LOCALAPPDATA%\hermes\skills\`, `%USERPROFILE%\.agents\skills\` (junction), `hermes-global-skills\`, `opencode\.agents\skills\` |

Secrets **nunca** embarcam: templates com placeholders + prompt/env no install (capability `agent-configs`).

- **Dirs:** `skills\` (árvore, 157 dirs) · `plugins\` (superpowers v6.3.0) · `gateway\` + `gateway-service\` · `kanban.db` · `state.db` (456MB) · `sessions\` · `memories\` · `profiles\` · `hooks\` · `cron\` · `platforms\` · `bin\` · `workspace\`

- **Binários/setup:** `hermes-setup.exe` · desktop app `AppData\Local\Programs\Hermes Studio\`

### OpenCode — `[CAMINHO]`
- **Configs:** opencode.json (9 providers, keys por `{env:}`) · `.env` (keys) · skills-lock.json (provenance nativa) · `rate-limit-fallback.json` (plugin)

### Obsidian — `%OBSIDIAN_VAULT_PATH%\.obsidian\`
