# Reaper-MCP

**Status:** 🟢 Ativo (v0.3.0)
**Local:** `[CAMINHO]`
**Stack:** Python 3.10+, MCP (FastMCP, mcp[cli]), mido, Lua (bridge REAPER)

## Descrição
Servidor MCP para produção musical com IA no REAPER DAW. 153 ferramentas em 24 módulos cobrindo transporte, tracks, MIDI, patterns, loops, FX, envelopes, sidechain, mixing, mastering, bus pipelines e análise de áudio. Usa IPC via arquivo (command.json/response.json) com bridge Lua dentro do REAPER.

## Stack Completa
- **Python:** FastMCP, mido, 24 tool modules
- **Lua:** `reaper_mcp_server.lua` — bridge que roda dentro do REAPER
- **IPC:** File-based via `%TEMP%\reaper_mcp\` (command.json / response.json)

## Estrutura
```
[CAMINHO]
├── reaper_mcp/
│   ├── main.py                    # FastMCP server entry point
│   ├── tools/                     # 24 tool modules
│   │   ├── transport.py           # Play, stop, record, position
│   │   ├── track.py               # Create, delete, rename, mute, solo
│   │   ├── midi.py                # Notes, CC, patterns
│   │   ├── fx.py                  # Add, remove, configure plugins
│   │   ├── mix.py                 # Mix engine (EQ, comp, reverb)
│   │   ├── master.py              # Master chain (HP, bus comp, limiter)
│   │   └── ...                    # envelopes, sidechain, analysis, etc
│   └── mix_engine/                # Mixing/mastering pipelines
│       ├── catalog.py             # 25 style profiles
│       ├── edm.py                 # 11 EDM styles
│       ├── rock.py                # 6 Rock styles
│       ├── pop.py                 # 4 Pop styles
│       └── electronic.py          # 4 Electronic styles
├── reaper_scripts/
│   └── reaper_mcp_server.lua      # Lua bridge
├── install.bat                    # Windows installer
└── install.sh                     # Linux/macOS installer
```
