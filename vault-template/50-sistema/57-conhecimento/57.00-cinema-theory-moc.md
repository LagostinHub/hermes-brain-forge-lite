# 🎬 CINEMA THEORY — Map of Content (MOC)

> **Propósito:** Índice mestre do domínio de conhecimento cinematográfico completo. Integra áudio (já estruturado) com 6 pilares de produção audiovisual que compõem todo o conhecimento pesquisado a partir de livros fundamentais.
>
> **Total:** 7 MOCs (1 áudio + 6 pilares). Cada um com decision cards no formato CONTEXTO / QUANDO USAR / O QUE FAZ / PORQUÊ / EXCEÇÃO / SINAIS DE ERRO.
>
> **Fontes primárias gerais:** Murch (In the Blink of an Eye), Mascelli (Five C's), Williams (Animator's Survival Kit), McKee (Story), Field (Screenplay), Eisenstein, Bordwell/Thompson, Bresson, Ruy Guerra, Zeca Ferreira, Richard Williams, Halas & Whitaker, Thomas & Johnston, Lupton, Heller, Dondis — mais 11 arquivos de áudio já estruturados.

## 🏗️ ARQUITETURA DA TREE — POR QUE ÁUDIO TEM ARQUIVOS SEPARADOS

O áudio é **um pilar igual aos outros 6** — a diferença é só a organização INTERNA, que segue a natureza do conteúdo:

| | Pilares 57.20–57.25 (roteiro→design) | Pilar 57.26 (áudio) |
|---|---|---|
| **Natureza** | Teórico-decisório (regras de livros) | Procedural (pipeline técnico) |
| **Estrutura** | 1 MOC com cards embutidos (8–33 cards) | 1 MOC + 11 arquivos de domínio (1 por etapa) |
| **Consulta** | Por pilar ("estou escrevendo" → roteiro) | Por etapa ("estou mixando" → mixagem) |
| **Formato de card** | FONTE/CONTEXTO/QUANDO/FAZ/PORQUÊ/EXCEÇÃO/EXEMPLOS/CONTRA-EXEMPLO | Idêntico |

A unidade de consulta tem o mesmo peso (~13–41K por arquivo). Nenhuma das duas organizações é "melhor" — cada uma serve a natureza do seu conteúdo.

## 📖 ORDEM DE LEITURA — 4 FASES

### FASE 1 — FUNDAMENTOS (Iniciante → Intermediário)
**Objetivo:** Entender os sistemas básicos antes de aplicar regras.

| Ordem | Card / MOC | Por quê |
|-------|------------|---------|
| 1 | **Áudio** — 57.01-fundamentos + 57.02-producao | Áudio é 50% da experiência cinematográfica. Começar aqui dá visão completa do pipeline. |
| 2 | **Roteiro** — R-01 (3 Atos), R-02 (Plot Points), R-03 (Premissa), R-05 (Inciting Incident) | É a espinha dorsal. Sem estrutura, nada mais funciona. |
| 3 | **Cinematografia** — C-01 (5 C's), C-02 (180°), C-03 (direção de tela), C-05 (3 pontos de luz) | A gramática visual mínima para planejar qualquer cena. |
| 4 | **Animação** — A-01 (timing + spacing), A-02 (bola quicante), A-04 (ease in/out), A-05 (antecipação) | Princípios de movimento que valem para tudo — não só animação. |

**Teste de competência:** Consegue estruturar um logline em 3 atos com plot points e arco de personagem, e descrever a iluminação básica para cada ato?

## 🛠️ COMO UM AGENTE USA ESTE SISTEMA

Quando um agente é acionado para um projeto de cinema, ele:

1. **Identifica o contexto:** Qual fase do projeto? (pré-produção, produção, pós-produção)
2. **Carrega o MOC mestre:** `57.00-cinema-theory-moc.md` — sempre carrega este primeiro para saber quais MOCs são relevantes
3. **Carrega os MOCs específicos:** Conforme a necessidade (roteiro, cinematografia, edição, etc.)
4. **Para cada decisão:** Consulta o card correspondente no formato DECISION CARD (QUANDO USAR / O QUE FAZ / PORQUÊ / EXCEÇÃO)
5. **Consulta os cross-references:** Verifica como a decisão afeta os outros pilares
6. **Aplica com contexto:** Usa as regras com a nuance do projeto específico

**Exemplo — um agente editando um rough cut:**

```
1. Carrega 57.00-cinema-theory-moc.md → identifica que edição (57.22) é o foco
2. Carrega 57.22-edição-moc.md → consulta os 12 cards de decisão de corte
3. Para cada corte difícil: consulta E-01 (Regra dos 6) → avalia emoção → história → ritmo → eye-trace → planura → 3D
4. Se corte "tecnicamente certo" mas sente "atrasado": consulta E-02 (piscar como guia)
5. Verifica cross-references: como o corte afeta a narrativa (R-04), a cobertura (C-01), o movimento (A-05)
6. Se precisar de som: consulta 57.26-audio-moc.md e o card de áudio relevante
```

## 📝 NOTAS DE GESTÃO

- **Ordem de numeração:** 57.00 = Cinema Theory (MOC mestre). Os 7 PILARES são os MOCs 57.20–57.26: roteiro, cinematografia, edição, montagem, animação, design, áudio. O pilar áudio (57.26) tem 11 CARDS S-01→S-11 **embutidos** no MOC + 10 arquivos de domínio (57.01–57.10) como referência profunda.
- **Padrão de card:** `[CÓDIGO] TÍTULO` seguido de QUANDO / FAZ / PORQUÊ / EXCEÇÃO / SINAIS DE ERRO / APLICAÇÃO (quando aplicável)
- **Códigos:** `[ÁREA]-[NUM]` — R (roteiro), C (cinematografia), E (edição), G (montagem), A (animação), D (design), S (áudio)
- **MOC mestre é a entrada obrigatória:** Sempre carregar `57.00-cinema-theory-moc.md` antes de qualquer um dos sub-MOCs — ele define qual MOC é relevante para o contexto
- **Áudio é especial:** Os 11 cards de áudio são muito mais detalhados (com ferramentas, taxons, casos de uso) porque são o domínio mais amadurecido. Os de cinema são mais concisos — focados em decisão, não em procedimento técnico
- **Fontes:** Os .txt fonte (`regras_COMPILADAS_FINAL.txt` e `regras_GRUPOS_1-4.txt`) são a fonte de verdade das regras — atualizar quando novas regras são extraídas
