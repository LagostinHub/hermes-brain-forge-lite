## CONTEXTO — O que é masterização surround <a name="contexto"></a>

Masterização de áudio para cinema e streaming não é "deixar mais bonito" — é **traduzir a intenção artística através de múltiplos sistemas de reprodução** sem perda semântica. Holman (2011) define masterização surround como o processo de otimizar o mix para reprodução em sistemas que variam de 5.1 (salas de cinema) a 7.1.4 Atmos (salas Dolby Atmos) até estéreo downmix (TVs, celulares, laptops).

A masterização moderna é **multi-formato por natureza**: um único master precisa servir theatrical (Dolby Atmos cinema), streaming (Dolby Atmos via IAB/ADM), broadcast (5.1), e downmix estéreo — cada um com requisitos de loudness, faixa dinâmica, e mapeamento de canais distintos.

### A anatomia do problema

O áudio surround opera em duas filosofias distintas (Dolby Atmos Documentation, 2020):

- **Channel-based:** O áudio é mixado para posições fixas de caixas (ex: 5.1 = L, C, R, Ls, Rs, LFE). O mixer decide "este som vai para trás-esquerda."
- **Object-based:** Sons são tratados como objetos com metadados de posição (x, y, z) e o **renderer** do sistema de reprodução decide qual caixa acionar. O mixer diz "este som está em (x=0.3, y=0.8, z=0.5)" e o renderer mapeia para as caixas disponíveis.

Holman (2011, cap. 1) observa que o ouvido humano localiza som por três pistas:
1. **ITD (Interaural Time Difference):** diferença de tempo entre ouvidos (eficaz < 1.5 kHz)
2. **ILD (Interaural Level Difference):** diferença de nível (eficaz > 4 kHz)
3. **HRTF (Head-Related Transfer Function):** filtragem espectral pelo torso, cabeça e pavilhão auricular (localização vertical e frente/trás)

O surround explora essas pistas. O Atmos object-based as explora de forma adaptativa — o renderer aplica HRTF virtual quando necessário (ex: som "acima" em sistema sem caixas de altura).

## QUANDO USAR — Formatos e cenários de entrega <a name="quando-usar"></a>

### Matriz de decisão por entrega

| Cenário | Formato | Loudness alvo | Notas |
|---------|---------|---------------|-------|
| Cinema theatrical (Dolby) | Dolby Atmos (7.1.4 bed + objetos) | 85 dB SPL (C-weighted, slow) para diálogo | Medição com ruído rosa em cada canal |
| Streaming (Netflix) | Dolby Atmos IAB ou ADM BWF | −27 LUFS (±2.0) integrado | IAB = Dolby native; ADM BWF = padrão EBU |
| Streaming (Amazon/Apple) | Dolby Atmos ADM BWF | −27 LUFS | ADM BWF é o padrão aberto |
| Broadcast TV (Brasil) | 5.1 + estéreo | −24 LUFS (ABNT NBR 15601) | Downmix obrigatório |
| Cinema não-Atmos | 7.1 ou 5.1 | 85 dB SPL | 7.1 adiciona Lsr/Rsr (back) |
| Web/social | Estéreo | −14 LUFS (YouTube) / −16 LUFS (Spotify) | Downmix de surround obrigatório |

### Quando escolher Atmos object-based vs 5.1/7.1 channel-based

**Use Atmos object-based quando:**
- O projeto será exibido em salas Atmos (cinema ou home theater)
- Há elementos que se movem no eixo vertical (z) — voos, chuva, explosões aéreas
- A entrega requer adaptação automática a múltiplos sistemas (Atmos renderer faz downmix para 7.1, 5.1, estéreo, binaural)
- O orçamento permite renderer Dolby e monitoramento 7.1.4

**Use 5.1/7.1 channel-based quando:**
- A entrega principal é broadcast ou streaming sem Atmos
- O estúdio não tem certificação Dolby ou renderer
- O projeto é estéreo com upmix (não recomendado como master primário)
- Prazo/orçamento não permitem mixagem object-based

Holman (2011, cap. 8) alerta: **mixar em 5.1 e "upmixir" para Atmos perde a resolução espacial** que o object-based oferece. O upmix (ex: Dolby Surround Upmixer) é uma adaptação, não um master.

## O QUE FAZ — Decisões técnicas e fluxos <a name="o-que-faz"></a>

### 1. Comparação de formatos surround

#### 5.1 (ITU-R BS.775)
- **Canais:** L (30°), C (0°), R (−30°), Ls (110°), Rs (−110°), LFE (< 120 Hz)
- **Ângulo entre L/R:** 60° — compatível com estéreo
- **Ângulo entre Ls/Rs:** 110° — atrás do ouvinte, ligeiramente para os lados
- **LFE:** dedicado a efeitos graves, crossover em 80–120 Hz (Holman recomenda 80 Hz para cinema)
- **Uso:** padrão mínimo para cinema e broadcast

#### 7.1 (ITU-R BS.2159)
- **Canais:** L, C, R, Lss (90°), Rss (−90°), Lsr (150°), Rsr (−150°), LFE
- **Diferença:** adiciona Lsr/Rsr (back) separando side de back
- **Problema:** compatibilidade com 5.1 — downmix de 7.1 para 5.1 requer soma de Lss+Lsr e Rss+Rsr com atenuação de −3 dB
- **Uso:** cinemas premium, home theaters

#### 7.1.4 Atmos (Dolby)
- **Bed:** 7.1 (canais fixos) + 4 overhead (TFL, TFR, TRL, TRR)
- **Objetos:** até 128 objetos simultâneos com metadados de posição
- **Renderer:** mapeia objetos para caixas disponíveis (adaptativo)
- **Downmix:** automático para 7.1, 5.1, estéreo, binaural
- **Uso:** cinema Atmos, streaming Atmos

#### Auro-3D (Auro Technologies)
- **Camadas:** Surround (5.1) + Height + Overhead (VOG — Voice of God)
- **Filosofia:** três camadas horizontais (surround, height, overhead) em vez de objetos
- **Compatibilidade:** downmix para 5.1 e estéreo
- **Uso:** menos comum que Atmos, mas presente em salas Auro

#### DTS:X (DTS)
- **Filosofia:** object-based como Atmos, mas com flexibilidade de speaker layout
- **Diferença:** não exige layout fixo — o renderer adapta aos alto-falantes disponíveis
- **Uso:** cinemas DTS:X, alguns streamings

### 2. Atmos: Objects vs Beds

**Beds (canais fixos):**
- 7.1.4 bed = 12 canais de áudio fixo
- Usado para: ambiente, reverberação, música, elementos estáticos
- Ocupa largura de banda fixa (12 × 48 kHz × 24 bit = ~13.8 Mbps sem compressão)

**Objetos:**
- Até 128 objetos com metadados (posição x,y,z, tamanho, ganho)
- Usado para: diálogos pontuais, efeitos em movimento, elementos interativos
- Ocupa largura de banda variável (áudio + metadados)
- **Vantagem:** adaptação automática — um objeto "acima" em 7.1.4 vira HRTF binaural em fones

**Decisão prática (Dolby Atmos Documentation, 2020):**
- Use beds para o "tapete sonoro" (base)
- Use objetos para elementos que se movem ou precisam de precisão espacial
- Não use objetos para tudo — o renderer tem limite de 128 e o custo computacional aumenta

### 3. Speaker placement (Holman, 2011, cap. 4–5)

#### 5.1 (ITU-R BS.775-3)
| Canal | Ângulo | Altura | Observação |
|-------|--------|--------|------------|
| L | +30° | Orelha | Forma triângulo equilátero com R e ouvinte |
| R | −30° | Orelha | |
| C | 0° | Orelha | Central, atrás da tela perfurada (cinema) |
| Ls | +110° | Orelha | Ligeiramente atrás |
| Rs | −110° | Orelha | |
| LFE | — | Chão | Subwoofer, canto frontal preferencial |

**Regra de ouro de Holman:** o ângulo entre L e R deve ser 60° (30° cada) para compatibilidade estéreo. Ls/Rs a 110° (não 180°) porque o ouvido humano localiza melhor sons laterais do que traseiros puros.

#### 7.1.4 Atmos (Dolby, 2020)
| Canal | Ângulo | Altura | Nome |
|-------|--------|--------|------|
| L | +30° | Orelha | Front Left |
| R | −30° | Orelha | Front Right |
| C | 0° | Orelha | Center |
| Lss | +90° | Orelha | Side Surround Left |
| Rss | −90° | Orelha | Side Surround Right |
| Lsr | +150° | Orelha | Back Surround Left |
| Rsr | −150° | Orelha | Back Surround Right |
| LFE | — | Chão | Subwoofer |
| TFL | +45° | 45° acima | Top Front Left |
| TFR | −45° | 45° acima | Top Front Right |
| TRL | +135° | 45° acima | Top Rear Left |
| TRR | −135° | 45° acima | Top Rear Right |

**Altura (Dolby recomenda):** 45° acima do plano de orelha. Menos que 30° e o cérebro localiza como "lateral"; mais que 60° e perde integração com o plano horizontal.

### 4. Bass Management (Holman, 2011, cap. 6)

Bass management é o sistema que redireciona frequências graves de qualquer canal para o subwoofer (LFE) ou para caixas full-range que possam reproduzi-las.

**Componentes:**
1. **High-pass filter (crossover):** remove graves de canais satélite (tipicamente 80 Hz, 24 dB/octave Linkwitz-Riley)
2. **LFE channel:** dedicado a efeitos graves (< 120 Hz), reproduzido pelo subwoofer
3. **Bass redirection:** frequências abaixo do crossover de cada canal são somadas ao sub

**Configurações recomendadas:**
- **Cinema:** crossover em 80 Hz (THX standard), LFE em 120 Hz
- **Streaming/doméstico:** crossover em 80–100 Hz dependendo das caixas
- **Estéreo downmix:** bass management crítico — sub grave sem controle destrói o downmix

**Atenção (Holman, 2011, p. 142):** o LFE é reproduzido com +10 dB de ganho no cinema (calibração). No downmix para estéreo, o LFE é atenuado em −10 dB ou descartado. Nunca entregue um master com LFE como única fonte de grave — o downmix perde o grave.

### 5. Downmixing

**De 5.1 para estéreo (Lt/Rt ou Lo/Ro):**
- **Lt/Rt (Dolby Surround):** codifica Ls/Rs em fase para decodificação Pro Logic. Compatível com decodificadores Dolby.
- **Lo/Ro (estéreo simples):** soma Ls a L (−3 dB), Rs a R (−3 dB), C a L+R (−3 dB), LFE descartado ou atenuado.

**De 7.1 para 5.1:**
- Lss+Lsr → Ls (soma com −3 dB)
- Rss+Rsr → Rs (soma com −3 dB)
- Tops descartados ou fold-down para Ls/Rs

**De Atmos para 7.1/5.1/estéreo:**
- O renderer Dolby faz o downmix automaticamente
- Objetos são renderizados para as caixas disponíveis
- Para fones: renderiza como binaural (HRTF)

**Regra crítica (Netflix Sound Mix Specs, 2023):** sempre valide o downmix. Um mix que soa perfeito em 7.1.4 pode ter problemas de fase, cancelamento de grave, ou diálogo perdido no downmix estéreo. A Netflix exige que o master inclua downmix validado.

### 6. Theatrical vs Streaming vs Home Delivery

| Aspecto | Cinema Theatrical | Streaming (Netflix) | Home/TV |
|---------|-------------------|---------------------|---------|
| Loudness | 85 dB SPL (C, slow) | −27 LUFS (±2.0) | −24 LUFS (broadcast) |
| Faixa dinâmica | Alta (20+ dB) | Moderada (15–18 dB) | Comprimida (12–15 dB) |
| Formato | Atmos 7.1.4 + objetos | Atmos IAB ou ADM BWF | 5.1 ou estéreo |
| Monitoração | X-curve (cinema) | Plana (doméstica) | Plana |
| Calibração | SPL meter, ruôsa rosa | Medidor LUFS (ITU-R BS.1770) | Nenhuma |

**X-curve (Holman, 2011, cap. 3):** curva de equalização de salas de cinema. Acentua graves e agudos em baixa frequência para compensar a acústica de grandes salas. Em salas pequenas (home theater), a x-curve não se aplica — monitoração plana.

**Netflix Sound Mix Specs (2023):**
- Atmos IAB: formato Dolby nativo, entrega como arquivo IAB (Immersive Audio Bitstream)
- ADM BWF: padrão aberto EBU, entrega como Broadcast Wave com metadados ADM
- Ambos aceitos, mas IAB é preferido para projetos Atmos
- Stems obrigatórios: DME (Dialogue, Music, Effects) separados para localização

## EXCEÇÃO — Armadilhas e limites <a name="excecao"></a>

1. **Nunca confie apenas no subwoofer para graves.** O LFE é +10 dB no cinema mas atenuado no downmix. Grave principal deve estar nos canais full-range.

2. **Não mixe em 5.1 e entregue como "Atmos".** O upmix Dolby Surround Upmixer é uma adaptação, não um master. Perde resolução espacial e objetos não são recuperados.

3. **Cuidado com a soma de fase no downmix.** Ls e Rs fora de fase podem cancelar no downmix estéreo. Sempre verifique mono compatibility.

4. **Não use crossover acima de 100 Hz em sistemas domésticos.** Acima disso, graves se tornam localizáveis e o subwoofer perde a "invisibilidade".

5. **Atmos objects não são "mágica".** O renderer tem limite de 128 objetos. Objetos demais competem por recursos e podem causar artifacts.

6. **X-curve não se aplica a home theaters.** Monitorar em x-curve em sala pequena resulta em mix com grave e agudo excessivos.

7. **Netflix exige loudness −27 LUFS ±2.0.** Fora disso, o arquivo é rejeitado ou normalizado automaticamente (destrói a dinâmica).

8. **ADM BWF vs IAB:** ADM BWF é mais compatível com sistemas não-Dolby, mas IAB preserva mais metadados Atmos. Escolha conforme o destino.
