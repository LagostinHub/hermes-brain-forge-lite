# Render Spec — Antes de renderizar QUALQUER coisa

> Lida por **qualquer agente** que roda Remotion. Falha se ignorar.

## ⚠️ VERDADE CANÔNICA (checar antes de tocar em codigo)

```
films/2026-09-09__V13__FINAL_entrega.mp4   ← aprovado. NÃO regredir.
```

## 🚫 PROIBIDO renderizar algo que:

1. **Use `spring()` ou `Easing`** — abre exceção só pra `@remotion/transitions` oficial
2. **Posicione com `top: NUMBER`** — usa sempre `SafeStack`/`SafeRow` (ver `motion-rules.md`)
3. **Não esteja em `Composition.tsx`** — não inventa composição nova sem aprovação humana
4. **Não valide no bancada de pixel** (`verifica_motion.py`, `verifica_layout.py`)
5. **Não pise na spec de entrega** (abaixo)

## ✅ CHECKS OBRIGATÓRIOS após render

| # | Check | Como validar |
|---|---|---|
| 1 | **0 frames pretos** | `ffmpeg -i x.mp4 -vf blackdetect -f null` → `black_start` = nenhum |
| 2 | **Duração áudio == vídeo** | `ffprobe` |
| 3 | **Loudness -14 LUFS** | Medir `ebur128` → aplicar `volume=-XdB` LINEAR (nunca `loudnorm`) |
| 4 | **True peak ≤ -1 dBTP** | `ebur128` |
| 5 | **Stream byte-identical** | `MD5` do vídeo antes/depois do `volume=` — têm que bater (prova que não re-encodou) |

> ⚠️ `loudnorm` é PROIBIDO (dinâmico). Usar `volume=XdB -c:v copy`.
