# 37.09 Skills Baseline (respirar)
> Baseline MANDATÓRIO herdado por todo agent/subagent/profile/bot. Bank = user-level (`~/.agents/skills`, **187** skills) + hermes-tree (`~/AppData/Local/hermes/skills`, **223**) = **~410** via `skills.paths`. O número **varia** com adições/arquivamentos — para recontar: `find <dir> -name SKILL.md | wc -l`. Pipeline por papel: [[Metodo de Trabalho]] §8. Inventário: [[35.06-skills-bank-manifest]].
