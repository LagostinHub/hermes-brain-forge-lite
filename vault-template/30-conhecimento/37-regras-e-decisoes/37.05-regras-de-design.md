# 37.05 — Regras de Design Gráfico

> **Fonte:** Lupton, Heller, Williams, Dondis, Meggs
> **Skills linkadas:** [[37.00-_index]] `design-decisions`

---

## 1. Os 4 Princípios Básicos (Robin Williams)

1. **Proximidade** — elementos relacionados ficam próximos
2. **Alinhamento** — tudo deve estar alinhado a algo
3. **Repetição** — repita elementos visuais (cores, fontes, formas)
4. **Contraste** — crie diferença para gerar interesse

Resolvem 90% dos problemas de design.

---

## 2. Tipografia é Arquitetura 2D (Lupton)

Type é linguagem. Na micro-nível, é desenho. Na macro-nível, é textura. Você "sente" a tipografia antes de lê-la — o visual comunica antes das palavras.

---

## 3. Escolha de Tipos (Lupton)

| Tipo | Personalidade |
|------|---------------|
| Serif | Tradicional, confiável, literário |
| Sans-serif | Moderno, limpo, direto |
| Display | Impacto, títulos, personalidade |
| Body | Leitura longa, neutro, funcional |

Cada fonte carrega associações culturais. A escolha errada contradiz a mensagem.

---

## 4. Kerning vs. Tracking (Lupton)

- **Kerning:** espaço entre pares de letras específico
- **Tracking:** espaço uniforme entre todas as letras

Espaçamento errado cria "buracos" visuais — o olho percebe antes da mente.

---

## 5. Psicologia das Cores (Eva Heller)

| Cor | Associações |
|-----|-------------|
| Vermelho | Amor, perigo, energia, urgência, paixão |
| Azul | Confiança, calma, intelecto, tristeza |
| Amarelo | Alegria, otimismo, atenção, ansiedade |
| Verde | Natureza, saúde, frescor, sorte, inveja |
| Laranja | Energia, criatividade, entusiasmo, juventude |
| Roxo | Luxo, espiritualidade, mistério, realeza |
| Branco | Pureza, paz, limpeza, simplicidade |
| Preto | Elegância, morte, poder, luto |

---

## 6. Contraste de Cor (Heller)

Use contraste complementar (opostos no círculo cromático) para chamar atenção. O olho humano é atraído por contraste — mecanismo de sobrevivência.

---

## 7. Sintaxe da Linguagem Visual (Dondis)

Elementos fundamentais:

| Elemento | Função |
|----------|--------|
| Ponto | Indica posição |
| Linha | Indica direção e movimento |
| Forma | Define áreas (geométrica, orgânica) |
| Cor | Evoca emoção |
| Textura | Tato visual |
| Escala/tamanho | Hierarquia visual |
| Espaço | Positivo (objeto) vs. negativo (fundo) |

Toda composição visual é construída a partir destes átomos.

---

## 8. Equilíbrio Visual (Dondis)

| Tipo | Efeito |
|------|--------|
| Simétrico | Formal, estável, clássico |
| Assimétrico | Dinâmico, interessante, moderno |

O cérebro busca equilíbrio. Composições desequilibradas geram desconforto.

---

## 9. Escala e Hierarquia (Dondis)

Tamanho = importância. O olho vai primeiro para o maior. Use escala para guiar a leitura.

---

## 10. Espaço Negativo (Dondis)

O espaço vazio não é "nada" — é um elemento de design. O espaço negativo define o positivo e cria respiro visual.

---

## 11. Tipografia: Tamanho e Legibilidade (Lupton)

Tamanho do corpo do texto depende:
- Distância de leitura (print vs. screen)
- Altura da letra "x" (x-height)
- Largura do tipo

**Regra geral:** 9-11pt para print, 16px+ para web.

---

## 12. Tipografia: Alinhamento (Lupton)

| Alinhamento | Efeito |
|-------------|--------|
| À esquerda | Natural, fácil de ler |
| À direito | Difícil de ler, exceto para textos curtos |
| Centralizado | Formal, elegante, difícil para textos longos |
| Justificado | Formal, pode criar "rios" de espaço |

---

## 13. Repetição e Consistência (Williams)

Repita: cores, fontes, formas, texturas, espaçamentos. A repetição cria unidade e profissionalismo.

---

## 14. Proximidade Organiza (Williams)

Elementos próximos são percebidos como relacionados. Use proximidade para criar grupos lógicos sem precisar de caixas ou linhas.

---

## 15. Contraste Cria Interesse (Williams)

Sem contraste, é monótono. Com contraste, você cria hierarquia e pontos focais.
