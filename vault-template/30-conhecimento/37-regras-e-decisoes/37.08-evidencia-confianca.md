# 37.08 Evidência e Confiança

> Regra de evidência forte + incerteza explícita. Ver também [[Tag Taxonomy]].

## Evidência forte (Lesson 8)

Padrão obrigatório para afirmações não-triviais:

```text
[Source: "citação com as palavras originais" → [[Wikilink Alvo]] + YYYY-MM-DD]
```

Regras:

- Manter as **palavras originais** (quote), não só a referência.
- Sempre `[[wikilink]]` + data da fonte.
- Uma afirmação sem quote é hipótese, não fato — marcar `status: unverified`.

## Confiança e incerteza (Lesson 10)

Campo `confidence:` no frontmatter com valores:

- `high` — múltiplas fontes / verificado em execução.
- `medium` — uma fonte boa ou inferência razoável.
- `low` — hipótese, memória fraca, fonte única fraca.

Combinar com `status:`:

- `active` — confiável para uso.
- `unverified` — precisa checagem antes de usar como base.
- `deprecated` — substituído, manter por histórico (nunca deletar).

## Fila de revisão

- Notas com `status: unverified` ou `confidence: low` entram na fila de revisão.
- Revisar por: checar fonte → confirmar quote → elevar `confidence` / mudar `status` para `active`.
- Nunca tratar `unverified` como certo em decisões downstream.

## Rejeitados (Lesson 5)

Toda nota de regra/decisão e todo Context Pack / Resource deve ter seção:

```markdown
## Rejected / Considered
- Rejeitado: <opção> — motivo: <razão> — ex.: <exemplo>
```

Registrar o que foi considerado e por que foi descartado evita re-trabalho.
