# shadcn/ui

**GitHub:** https://github.com/shadcn-ui/ui
**Stars:** 124.2k
**Stack:** React + Tailwind CSS + Radix UI (primitivas)
**License:** MIT

## O que é

**shadcn/ui não é uma biblioteca instalável** — é um **sistema de componentes copy-paste**. Você "instala" componentes individuais que vão diretamente para sua pasta `components/`, e eles são **totalmente customizáveis** (não são um pacote fechado como MUI).

Baseado em **Radix UI Primitives** (componentes acessíveis e sem estilo) + **Tailwind CSS** para estilização. Você pega o código, cola no seu projeto, e modifica como quiser — nada de CSS encapsulado ou overrides de tema.

## Arquitetura

```
components/
├── ui/          ← Componentes shadcn (botões, cards, dialogs, etc.)
│   ├── button.tsx
│   ├── dialog.tsx
│   └── ...
└── ...          ← Seus componentes
```

## Patterns

- **Composition via props** — `asChild`, slot patterns
- **CSS Variables** — tema light/dark via `hsl()` no Tailwind
- **`cn()`** — utilitário para merge de classes (tailwind-merge)
- **`useToast()`** — sistema de toasts via Sonner

## Prós

- Código 100% seu (não é black-box)
- Acessibilidade garantida (Radix)
- Dark mode built-in
- Comunidade enorme → muitos exemplos/copy-paste
- Expandível: você pode registrar e compartilhar seu próprio component

## Contras

- Pode gerar bloat se não for selective (instalar tudo de uma vez)
- A dependência de Radix UI adiciona bundle se não tree-shaking bem

## Uso típico

```bash
npx shadcn-ui@latest init
npx shadcn-ui@latest add button
npx shadcn-ui@latest add card
npx shadcn-ui@latest add form
```
