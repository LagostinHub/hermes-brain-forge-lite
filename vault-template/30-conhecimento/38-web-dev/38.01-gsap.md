# GSAP (GreenSock Animation Platform)

**GitHub:** https://github.com/greensock/gsap
**Stars:** 28.5k
**License:** GreenSock standard license (100% free, incl. bonus plugins)
**Último release:** v3.15.0 (Apr 2026)

## Descrição
JavaScript animation library. A referência para animação web com timing preciso, SVG, scroll-driven animations e timelines complexas. Todo o pacote (incl. SplitText, MorphSVG, ScrollTrigger, ScrollSmoother) é free.

## Plugins principais
- **ScrollTrigger** — Animação scroll-driven (padrão de fato para scroll animations)
- **ScrollSmoother** — Smooth scroll + parallax
- **SplitText** — Split de texto em chars/words/lines para animação
- **MorphSVG** — Morph de SVGs
- **Draggable, Observer, Flip** — Interatividade

## React
- Pacote `@gsap/react` expõe `useGSAP()` hook — drop-in replacement para `useEffect`/`useLayoutEffect`
- Automatiza cleanup

## Quando usar
- Animação JS nativa (sem framework)
- Scroll-driven animations precisas
- SVG morphing e text splitting
- Timeline orchestration complexa
