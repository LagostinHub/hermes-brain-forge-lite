# Next.js + shadcn Starters & Templates

Templates prontos para acelerar o início de projetos web.

## 📋 Comparativo rápido

| Template | Stack | Destaque | Prós | Contras |
|----------|-------|----------|------|---------|
| **shadcn-landing-page** | Next.js 15 + shadcn/ui + Tailwind + TS | Landing page hero/sliders/fit | Pro: copy-paste landing specs; Con: focado só em landing |
| **ixartz/SaaS-Boilerplate** | Next.js 16 + shadcn + Tailwind v4 + TS | SaaS completo (auth, billing, team) | Pro: tudo incluído (Sentry, I18n, Stripe); Con: complexo p/ landing simples |
| **Next-JS-Landing-Page-Starter** | Next.js 14 + Tailwind + TS | Landing page clean | Pro: dev experience first; Con: sem shadcn |
| **chadnext** | Next.js 14 + shadcn + LuciaAuth + Prisma | Full-stack com auth | Pro: inclui auth completo; Con: precisa adaptar |
| **Startup Next.js** | Next.js + shadcn + Tailwind | Startup/SaaS | Pro: template business pronto; Con: menos custom |
| **next-saas-starter** | Next.js + Postgres + Stripe + shadcn | SaaS com DB | Pro: postgres local; Con: over-engineering p/ landing |

## 📦 shadcn-landing-page (recomendado p/ landing)

**GitHub:** https://github.com/leoMirandaa/shadcn-landing-page
**Stack:** Next.js 15 + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui
**License:** MIT

### Features
- Landing page hero section com animações
- Seções: Hero, Features, CTA, FAQ, Footer
- Componentes shadcn/ui integrados
- Dark mode
- Fully responsive

### Usage
```bash
git clone https://github.com/leoMirandaa/shadcn-landing-page.git
cd shadcn-landing-page
npm install
npm run dev
```

## 🚀 ixartz/SaaS-Boilerplate (recomendado p/ SaaS)

**GitHub:** https://github.com/ixartz/SaaS-Boilerplate
**Stack:** Next.js 16 + React 19 + Tailwind CSS v4 + TypeScript + shadcn/ui

### Features
- Authentication (NextAuth)
- Billing (Stripe)
- Multi-tenancy + Teams
- Role & Permission
- Database (PgLite local)
- I18n
- SEO optimization
- Testing (Vitest, Playwright)
- Monitoring (Sentry)

### Usage
```bash
git clone https://github.com/ixartz/SaaS-Boilerplate.git my-saas
cd my-saas
npm install
npm run dev
```

## 🔧 Next-JS-Landing-Page-Starter (recomendado p/ speed)

**GitHub:** https://github.com/ixartz/Next-JS-Landing-Page-Starter-Template
**Stack:** Next.js 14 + TypeScript + ESLint + Prettier + Husky + Tailwind CSS

### Features
- Landing page template
- Dark/light mode
- SEO optimized
- Deploy to Netlify

## 🏁 Como escolher

| Precisa | Template |
|---------|----------|
