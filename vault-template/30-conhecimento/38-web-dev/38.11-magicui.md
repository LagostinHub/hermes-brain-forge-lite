# Magic UI

**GitHub:** https://github.com/magicuidesign/magicui
**Stars:** 22.3k
**License:** MIT
**Site:** https://magicui.design

## Descrição
UI library para design engineers. Componentes animados e efeitos que podem ser copiados e colados (copy-paste) nos seus apps. Foco em landing pages.

## Stack
- React + TypeScript
- Tailwind CSS
- Framer Motion (Motion)
- shadcn/ui

## Quando usar
- Landing pages com micro-interações animadas
- Headers, footers, feature sections, CTAs
- Quando precisa de algo entre React Bits (mais pesado) e CSS puro (Galaxy)
