# Radix UI Primitives

**GitHub:** https://github.com/radix-ui/primitives
**Stars:** 30.2k
**Stack:** React (headless/unstyled)
**License:** MIT

## O que é

**Primitivas de UI acessíveis e sem estilo** para React. Radix não fornece nenhuma aparência — são componentes funcionais (como Dropdown, Dialog, Tooltip, Tabs) que você estiliza do jeito que quiser.

É a **base por trás do shadcn/ui** — shadcn pega as primitivas do Radix e adiciona estilização Tailwind.

## Primitivas disponíveis

| Categoria | Primitivas |
|-----------|-----------|
| **Overlays** | Dialog, Alert Dialog, Popover, Tooltip, Hover Card, Context Menu |
| **Inputs** | Checkbox, Radio Group, Slider, Switch, Text Field, Text Area |
| **Navigation** | Tabs, Dropdown Menu, Navigation Menu, Menubar, Select |
| **Layout** | Avatar, Collapsible, Separator, Skeleton, Slot |
| **Feedback** | Toast, Progress, Meter |

## Arquitetura

Tudo via **composition** — você compõe primitivas para criar componentes mais complexos:

```tsx
import * as Dialog from '@radix-ui/react-dialog';

<Dialog.Root>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Overlay />
    <Dialog.Content>
      <Dialog.Title>Title</Dialog.Title>
      <Dialog.Description>Desc</Dialog.Description>
      <Dialog.Close />
    </Dialog.Content>
  </Dialog.Portal>
</Dialog.Root>
```
