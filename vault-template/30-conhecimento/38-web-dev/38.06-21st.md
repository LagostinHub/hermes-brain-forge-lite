# 21st

**GitHub:** https://github.com/serafimcloud/21st
**Stars:** 5.5k
**License:** MIT
**Site:** https://21st.dev
**Stack:** Next.js, React, Tailwind, shadcn/ui

## Descrição
"npm for design engineers" — marketplace de componentes React Tailwind baseados em shadcn/ui. Componentes passam por processo de review antes de serem featured.

## Arquitetura
- `apps/` — aplicações (web, registry)
- `packages/` — pacotes compartilhados
- `content/docs/` — documentação
- `registry/` — source de truth dos componentes
- `__registry__/` — artifacts gerados
- `supabase/` — backend (user data, likes, etc.)
- `mcp/` — integração MCP

## Workflow de publicação
1. Desenvolvedor publica componente → estado `on_review`
2. Review manual por Serafim → `posted`
3. Featured no homepage → `featured`

## Quality Standards
- Visual polished, light/dark theme support
- Seguir padrão shadcn (component logic separado do demo)
- CSS variables do shadcn theme (`hsl(var(--background))`)
- Acessibilidade (ARIA, keyboard nav, contraste)
- TypeScript best practices
- Responsive

## Quando usar
- Componentes shadcn-based de alta qualidade
- Marketplace de blocos prontos para Next.js
- Componentes que passaram por QA de design
