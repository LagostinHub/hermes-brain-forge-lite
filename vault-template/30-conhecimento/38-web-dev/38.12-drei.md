# Drei

**GitHub:** https://github.com/pmndrs/drei
**Stars:** 9.9k
**License:** MIT
**Docs:** https://drei.docs.pmnd.rs

## Descrição
Coleção de helpers, hooks e componentes para react-three-fiber. Não é uma library de componentes UI — é um conjunto de utilities para facilitar uso de Three.js + React.

## Funcionalidades principais
- **Câmeras:** `PerspectiveCamera`, `OrthographicCamera`, `CameraControls`
- **Controles:** `OrbitControls`, `PointerLockControls`, `KeyboardControls`
- **Carregamento:** `useGLTF`, `useFBX`, `useAnimations`, `useTexture`
- **Pré-configurados:** `Environment`, `ContactShadows`, `Stats`, `Perf`
- **UI 3D:** `Text`, `Html`, `Text3D`, `Billboard`
- **Efeitos:** `Bloom`, `EffectComposer`, `Vignette`
- **VR/XR:** `XR`, `Controllers`, `Hands`

## Instalação
```bash
npm install @react-three/drei
# ou
npm install @react-three/drei/native  # para mobile
```

## Quando usar
- Qualquer projeto R3F — Drei é praticamente obrigatório
- Components: usar `useGLTF` para assets, `Environment` para lighting
- Controles: `OrbitControls`, `KeyboardControls` prontos
- Post-processing: `EffectComposer` + efeitos
