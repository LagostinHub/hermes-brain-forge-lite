# site-builder

> **Use when** an agent needs to build a complete site, landing page, or web app — from scratch or refactoring. This skill is the **master router** that connects all frontend skills, tool references, and component libraries in the [DONO] vault.
>
> **Pré-requisito:** Load `frontend-skills` (React/Next.js/Tailwind fundamentals) and `design-decisions` (CRAP/Lupton/Heller D-08) first.

## 🌟 O QUE ESTA SKILL FAZ

**site-builder** é a skill de orquestração para agentes construindo páginas web. Ela não implementa nada sozinha — ela **roteia** para as skills especializadas corretas com base no contexto do projeto.

### FASE 5: ANIMAÇÕES — Motion design

#### Decision tree: biblioteca de animação

```
React + declaram? → Framer Motion [[38.02-motion]]
React + física? → react-spring [[38.17-react-spring]]
JS nativo? → GSAP [[38.01-gsap]]
Elementos decorativos? → React Bits [[38.04-react-bits]] (gratuito)
3D? → R3F + react-spring/three [[38.15-r3f]]
```

#### Regras de motion (da skill cliente-a):

- **Timing:** ~9f/beat (BPM-timed)
- **Transições:** 6-8f full-cover
- **Center text** — texto sempre centrado
- **≥8% density** — minimizar buracos visuais
- **No white flash** — nunca branco puro em transição
- **Individual wiggle** — cada elemento entra com micro-movement individual

#### IN/OUT frame pattern (do contexto do usuário)

Para cada take de animação:
1. Defina o **frame IN** (estado inicial) → `from:`
2. Defina o **frame OUT** (estado final) → `to:`
3. Refine easing e timing
4. **Aprovação obrigatória** antes de gerar vídeo final

### FASE 6: BUILD & DEPLOY

#### Build pipeline (usando `vercel-deploy` + `vercel-react-best-practices`)

```bash
# 1. Lint + format
pnpm lint && pnpm format

# 2. Test (webapp-testing skill)
pnpm test

# 3. Build
pnpm build

# 4. Deploy no Vercel
npx vercel --prod
```

#### Performance checklist (`vercel-react-best-practices` — 70 rules)

- [ ] Tree-shake componentes não usados
- [ ] `loading.tsx` para routes lentas
- [ ] `next/image` para imagens (ou `unoptimized` se externo)
- [ ] Fontes otimizadas (`next/font` ou `fontsource`)
- [ ] Bundle < 200KB para homepage

**Skill de referência:** `vercel-deploy`, `webapp-testing`, `web-design-guidelines`

## 🎯 COMPONENT ARSENAL (cheat sheet)

### Landing page hero section

```tsx
// app/components/sections/HeroSection.tsx
import { motion } from 'framer-motion';
import { Button } from '@/components/ui/button';

export default function HeroSection() {
  return (
    <section className="min-h-screen bg-gradient-to-b from-slate-900 to-slate-950">
      {/* Background animado do React Bits */}
      <div className="absolute inset-0">
        {/* @ts-ignore */}
        <AnimatedGradientBackground />
      </div>
      
      <div className="relative container mx-auto px-4 py-32 text-center">
        <motion.h1 
          initial={{ opacity: 0, y: 20 }}
          animate={{ opacity: 1, y: 0 }}
          className="text-5xl md:text-7xl font-bold text-white mb-6"
        >
          Título impactante
        </motion.h1>
        <motion.p
          initial={{ opacity: 0, y: 20 }}
          animate={{ opacity: 0.5, y: 0 }}
          transition={{ delay: 0.1 }}
          className="text-xl text-slate-300 mb-8 max-w-2xl mx-auto"
        >
          Subtítulo explicativo
        </motion.p>
        <motion.div
          initial={{ opacity: 0, y: 20 }}
          animate={{ opacity: 1, y: 0 }}
          transition={{ delay: 0.2 }}
        >
          <Button size="lg">Call to Action</Button>
        </motion.div>
      </div>
    </section>
  );
}
```

### Card de produto

```tsx
// app/components/cards/ProductCard.tsx
import { motion } from 'framer-motion';
import { Card, CardContent, CardFooter, CardHeader, CardTitle } from '@/components/ui/card';
import { Button } from '@/components/ui/button';

export default function ProductCard({ product }) {
  return (
    <motion.div
      whileHover={{ scale: 1.02, y: -4 }}
      transition={{ type: "spring", stiffness: 300 }}
    >
      <Card className="bg-slate-800/50 border-slate-700">
        <CardHeader>
          <CardTitle className="text-white">{product.title}</CardTitle>
        </CardHeader>
        <CardContent>
          <p className="text-slate-300">{product.description}</p>
        </CardContent>
        <CardFooter>
          <Button>Learn More</Button>
        </CardFooter>
      </Card>
    </motion.div>
  );
}
```
