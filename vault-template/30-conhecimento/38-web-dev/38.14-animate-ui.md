# Animate UI

**GitHub:** https://github.com/imskyleen/animate-ui
**Stars:** 4.3k
**License:** MIT
**Site:** https://animate-ui.com

## Descrição
Distribuição open-source totalmente animada de componentes React. Componentes podem ser instalados via shadcn CLI, modificados e usados. Built with React, TypeScript, Tailwind CSS, Motion (Framer Motion) e Shadcn CLI.

## Stack
- React + TypeScript
- Tailwind CSS
- Motion (Framer Motion)
- shadcn CLI (registry-based installation)

## Quando usar
- Componentes animados instaláveis via shadcn
- Quando React Bits/21st não tem o componente específico
- Integração com workflow shadcn existente
