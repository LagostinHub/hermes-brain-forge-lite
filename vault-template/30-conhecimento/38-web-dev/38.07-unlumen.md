# Unlumen UI

**GitHub:** https://github.com/leovvx/unlumen-ui-docs
**Stars:** 63
**License:** MIT
**Site:** https://ui.unlumen.com/docs
**Stack:** Next.js 15, React, TypeScript, Tailwind, shadcn/ui

## Descrição
Documentação e registry de componentes open-source baseados em shadcn/ui. O repositório contém apenas componentes públicos; componentes comerciais/pro estão em repo privado separado.

## Arquitetura
- `app/` — docs site (Next.js App Router, basePath `/docs`)
- `content/docs/` — documentação em MDX
- `registry/` — source de truth (componentes públicos)
- `packages/ui/` — shared UI components
- `__registry__/index.tsx` — artifacts gerados
- `public/r/` — arquivos de registry gerados

## Registro workflow
```bash
pnpm registry:validate:sources  # valida metadata antes de gerar
pnpm registry:build             # gera artifacts via shadcn CLI
pnpm registry:validate:generated  # valida artifacts
```

## Requirements
- Node.js 22.18.0 (`.nvmrc`)
- pnpm 10.26.0 (via Corepack)

## Quando usar
- Componentes shadcn-based open source
- Docs site como referência
- Registry workflow formal (validate → build → validate)
