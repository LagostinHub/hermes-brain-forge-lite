# MotionSites.ai

**URL:** https://motionsites.ai
**Stack:** AI-generated site gallery

## Descrição
Galeria de sites designados com AI, filtráveis por categoria. Cada entry inclui screenshots + prompts (alguns exportáveis). Categories visíveis: Popular, Apps, Sections, Hero, Landing Page, SaaS, Agency, AI, Creative, Portfolio, Technology, Travel, Fintech, Wellness, Ecommerce, Fashion, Automotive, Luxury, 3D Website, Dashboard, Interactive.

## Categorias destacadas
- **Creative / Portfolio** — Future 3D Portfolio, Quantum Human, Anchor AI
- **Luxury** — Monolithic, Veyra Electric
- **AI / Tech** — Nival Cyberspace, Neural Pathway, ConSentinel, Mind AI
- **Websites 3D** — Particle Field, WebGL Portfolio
- **Fashion** — Orla Fashion
- **Ecommerce / Fintech** — Ascend, Sellix
- **Dashboard** — Axle Journey
- **Interactive** — Alethia, Orbit Stickers

## Features
- Busca e filtros por categoria
- Cada site tem screenshot + nome + categoria + tipo (Personal/Agency)
- Alguns prompts incluídos (ex: `?prompt=consentinel` no URL)
- Links para ferramentas de aprendizado (Design Rocket)

## Quando usar
- Inspiração visual para landing pages
- Referências de micro-interações e backgrounds
- Prompt examples para AI site generation
- Benchmark de tendências AI-designed
