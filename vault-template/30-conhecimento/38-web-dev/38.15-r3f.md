# react-three-fiber (R3F)

**GitHub:** https://github.com/pmndrs/react-three-fiber
**Stars:** 32.4k
**License:** MIT
**Docs:** https://r3f.docs.pmnd.rs

## Descrição
React renderer para Three.js. Permite construir cenas 3D de forma declarativa com componentes React, reutilizáveis e que reagem a state changes.

## Arquitetura
- Componentes declarativos para objetos Three.js (`<mesh>`, `<ambientLight>`, etc.)
- Hooks para interatividade (`useFrame`, `useThree`, `useLoader`)
- Reconciliador customizado que converte React tree → Three.js scene
- Compatível com React 19

## Uso típico
```tsx
import { Canvas } from '@react-three/fiber'
import { OrbitControls } from '@react-three/drei'

function Box() {
  return (
    <mesh>
      <boxGeometry />
      <meshStandardMaterial color="orange" />
    </mesh>
  )
}

<Canvas>
  <ambientLight />
  <pointLight position={[10, 10, 10]} />
  <Box />
  <OrbitControls />
</Canvas>
```

## Quando usar
- 3D declarativo em React
- Integração entre Three.js e React state
- Quando precisa de reatividade em cenas 3D
