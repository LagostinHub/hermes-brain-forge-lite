# Motion (Framer Motion)

**GitHub:** https://github.com/motiondivision/motion
**Stars:** 33.7k
**License:** MIT
**Último commit:** Sep 2026 (main)

## Descrição
Biblioteca de animação para React e JavaScript. Foca em API declarativa, spring physics e layout transitions. Muito popular para animações de presença (mount/unmount), drag, gesture e shared layout transitions.

## Principais features
- **API declarativa** — props como `initial`, `animate`, `exit`
- **Spring physics** — `type="spring"` com stiffness, damping, rest
- **Layout transitions** — `layout` prop anima mudanças de layout automaticamente
- **Presence** — `AnimatePresence` para animar mount/unmount
- **Drag & Pan** — gesture handler built-in
- **Shared layout** — `LayoutGroup` para animações entre componentes
- **SVG path drawing** — animação de traços SVG

## Quando usar
- Animação React declarativa
- Layout transitions (shared element)
- Drag interactions
- Presence animations (enter/exit)
- Spring-based motion (mais natural que easings fixos)
