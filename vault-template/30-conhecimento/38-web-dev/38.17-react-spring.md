# react-spring

**GitHub:** https://github.com/pmndrs/react-spring
**Stars:** 29.2k
**Stack:** React
**License:** MIT

## O que é

**Biblioteca de animação baseada em física de molas (spring physics)** para React. Diferente de GSAP (imperativo, Timeline) e Framer Motion (declarativo, mas com API de "variants"), react-spring usa ** Springs ** — valores interpolados que "se assentam" naturalmente, como uma mola física.

Faz parte do ecossistema **pmndrs** (mesmos criadores do React Three Fiber e Drei).

## Conceito central: Spring

```jsx
useSpring({
  from: { opacity: 0, y: -100 },
  to: { opacity: 1, y: 0 },
  config: { tension: 300, friction: 30 } // ou presets: 'slow', 'medium', 'fast', 'stiff', 'tiny'
})
```

Ao invés de definir `duration` e `ease`, você define `tension` (força da mola) e `friction` (resistência). O resultado é uma animação que "bate" e se estabiliza — muito natural.

## API principal

| Hook | Uso |
|------|-----|
| `useSpring` | Animação de um único elemento (objeto único) |
| `useSprings` | Múltiplos elementos (lista/array) |
| `useTrail` | Animação em cadeia (todos os filhos com delay) |
| `useTransition` | Entrar/sair (mount/unmount) com fade |
| `useMotionValue` | Value tracking manual (interop com Framer Motion) |
| `useSpringRef` | Controle imperativo (play/pause/reset) |

## Presets de configuração

```js
{
  default: { tension: 170, friction: 26 },
  slow: { tension: 170, friction: 10 },
  stiff: { tension: 200, friction: 15 },
  fast: { tension: 300, friction: 20 },
  wall: { tension: 500, friction: 50 },
}
```

## Interpolações

react-spring permite interpolar valores complexos:

```jsx
const styles = useSpring({
  height: isOpen ? '100%' : '0%',
  opacity: isOpen ? 1 : 0,
  transform: isOpen ? 'rotate(0)' : 'rotate(-90deg)',
})
```

E interpolações com unidades e cores:

```jsx
x.to({
  scale: [1, 1.5, 1],
  rotate: [0, 180, 360],
})
```

## Comparação: react-spring vs GSAP vs Framer Motion

| Característica | react-spring | GSAP | Framer Motion |
|---|---|---|---|
| Física | Springs (natural) | Interpolações lineares | Springs + easings |
| Performance | Otimizado (re-renders) | Otimizado (independentes) | Otimizado |
| API | Hook-based | Imperativo (Timeline) | Declarativo (variants) |
| Curva de aprendizado | Média | Média-Alta | Baixa (React) |
| Melhor para | UI natural, lists | Sequências complexas, scroll | Apps React |
