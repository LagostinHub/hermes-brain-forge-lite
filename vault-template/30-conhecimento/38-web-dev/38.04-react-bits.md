# React Bits

**GitHub:** https://github.com/DavidHDev/react-bits
**Stars:** 47.6k
**License:** MIT
**Site:** https://reactbits.dev
**Último commit:** Sep 2026

## Descrição
Maior coleção open-source de componentes React animados. 200+ componentes prontos (categorizados como Text, Background, UI, Micro). Cada componente é totalmente customizável.

## Estrutura
- `src/` — componentes organizados por categoria
- Cada componente: lógica + estilos Tailwind/CSS modules
- `scripts/` — sistema de geração/categoria
- `jsrepo.config.ts` — config para shadcn-style registry

## Categorias
- **Text** — animações de texto (typewriter, scramble, etc.)
- **Background** — backgrounds animados (partículas, gradientes, canvas)
- **UI** — componentes interativos (botões, cards, menus)
- **Micro** — micro-interações (30 componentes leves)

## Uso
Instalação via jsrepo (shadcn-style):
```bash
npx jsrepo add @reactbits/<component-name>
```

## Quando usar
- Prototipagem rápida de UIs animadas
- Textos animados e backgrounds
- Micro-interações sem reinventar
- Componentes que rodam no browser sem dependências pesadas
