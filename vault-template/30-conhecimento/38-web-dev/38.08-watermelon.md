# Watermelon Platform

**GitHub:** https://github.com/WatermelonCorp/watermelon-platform
**Stars:** 535
**License:** MIT
**Stack:** Bun, Next.js, TypeScript

## Descrição
Plataforma MCP (Model Context Protocol) com 850 exemplos de código indexados. Expõe ferramentas de busca, recuperação, inspiração, category browsing e page composition via MCP. Endpoint hospedado em `https://mcp.watermelon.sh/mcp`.

## Ferramentas MCP
- **search** — busca semântica/keyword em 850 exemplos
- **retrieval** — recupera código específico
- **inspiration** — inspiração por categoria
- **category** — navegação por categoria
- **page-composition** — composição de páginas

## Estrutura
- `mcp/` — diretrizes do servidor MCP
- `packages/cli/` — CLI para interação
- `worker/` — Cloudflare Worker (endpoint MCP)
- `skills/` — skills de agente
- `.mcp.json` — manifesto MCP
- `functions/api/` — edge functions

## Observações
- Usa Cloudflare Workers + Analytics Engine
- Não retém IP, sessões, prompts ou argumentos de ferramentas
- Suporte a Claude, Codex, Cursor via plugin MCP

## Quando usar
- Exemplos de código via MCP (agentes de IA)
- Search de inspiração/code snippets
- Composição de páginas a partir de exemplos reais
