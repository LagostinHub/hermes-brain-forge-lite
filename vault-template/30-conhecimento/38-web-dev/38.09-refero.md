# Refero Skill

**GitHub:** https://github.com/referodesign/refero_skill
**Stars:** 270
**License:** MIT
**Site:** https://doc.refero.design/mcp/getting-started

## Descrição
Skill de design research-first para agentes de IA. Fornece acesso a 150.000+ telas reais de apps e 6.000+ user flows de produtos bem projetados. Pesquisa é obrigatória antes da implementação — o agente deve validar estilos visuais antes de codar.

## Metodologia
1. **Discovery** — entender requisitos
2. **Research** — buscar referências reais (150k+ telas)
3. **Analyze** — extrair padrões visuais
4. **Design** — aplicar estilos validados
5. **Implement** — codar com constraints de design comprovadas

## Instalação
