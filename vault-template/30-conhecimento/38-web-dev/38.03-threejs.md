# Three.js

**GitHub:** https://github.com/mrdoob/three.js
**Stars:** 115.7k
**License:** MIT
**Último commit:** Sep 2026 (dev branch)

## Descrição
JavaScript 3D library — WebGL, WebGPU, WebXR. A biblioteca mais popular para 3D na web. Fornece cenas, câmeras, geometria, materiais, iluminação, animação e controle de arquivos 3D.

## Stack
- **Core:** WebGL (WebGL 1/2)
- **Modern:** WebGPU (experimental)
- **Modules:** TSL (Three.js Shader Language) para shaders declarativos
- **XR:** WebXR (VR/AR)
- Exemplos: /examples com loaders, controles, postprocess

## Arquivo
- `three/` — lib com fonte e exemplos
- `build/` — bundles prontos
- `src/` — source modular
- `examples/` — exemplos interativos + loaders (GLTF, FBX, etc.)

## Quando usar
- 3D interativo na web
- Visualizações WebGL/WebGPU
- Integração com React via `@react-three/fiber`
- Experiências imersivas (VR/AR)
