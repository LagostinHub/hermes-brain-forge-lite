# Taroth Landing Page — Implementation

> Landing page para o app **Tarô & Cabala** (Thoth Tarot + Qabalah). Segue o workflow `site-builder` fases 1-6.

## FASE 1: CONTEXT

- **Propósito:** Landing page que apresenta a plataforma de estudo de Tarô de Crowley/Thoth e Cabala Hermética
- **Público:** Estudiosos, praticantes de tarô ocultista, interessados em Crowley/Thoth
- **Formato:** Desktop-first, dark/mystical, scroll-driven
- **Deploy:** Vercel (já existente em `taroth-app.vercel.app`)
- **Diferencial:** 271 conteúdos × 4 fontes, 88 imagens, árvore D3, /estudo SM-2

## FASE 2: ARCHITECTURE

- **Framework:** Next.js 14.2.5 (App Router) — já existente
- **CSS:** Tailwind CSS 3.4.6 — já existente
- **Animação:** Framer Motion (a ser adicionado)
- **Component library:** shadcn/ui patterns (clsx, lucide-react) — já usado parcialmente
- **Paleta:** Taroth — `#0a0a0f` (bg), `#16161f` (card), `#1a1a28` (tertiary), `#c9a96e` (gold accent)

## FASE 5: ANIMAÇÕES

Regras aplicadas (da skill `cliente-a-video-motion`):
- **IN/OUT frame pattern:** Hero entra de `opacity:0, y:40` → `opacity:1, y:0`
- **Timing:** stagger de 0.1s entre elementos (BPM-timed ~9f)
- **No white flash:** fundo #0a0a0f (nunca branco)
- **Hover:** scale 1.02 + gold glow (transition suave)
