# Galaxy (UIverse)

**GitHub:** https://github.com/uiverse-io/galaxy
**Stars:** 13k
**License:** MIT
**Site:** https://uiverse.io/

## Descrição
Arquivo/repositório com 3000+ elementos UI feitos pela comunidade Uiverse.io. Cada elemento é CSS puro ou Tailwind, pronto para copiar e colar. Não é uma library instalável — é um archive de snippets.

## Estrutura
Organizado por tipo de componente (pastas no repo):
- `Buttons/`, `Cards/`, `Forms/`, `Inputs/`
- `Checkboxes/`, `Radio-buttons/`, `Toggle-switches/`
- `Notifications/`, `Tooltips/`, `Patterns/`
- `loaders/`

## Contribuição
- Elementos são submetidos via https://uiverse.io/
- Aprovação manual por [Serafim](https://x.com/serafimcloud) antes de aparecer no repo
- Aprovação garante: visual polished, light/dark, acessibilidade básica, responsive

## Quando usar
- Snippets CSS/Tailwind prontos
- Inspiração rápida para componentes
- Copy-paste de micro-interações CSS-only
- UI que não precisa de bundle JS
