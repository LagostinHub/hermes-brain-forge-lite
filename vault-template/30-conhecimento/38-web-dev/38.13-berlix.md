# Berlix

**GitHub:** https://github.com/reche13/berlix
**Stars:** 48
**License:** MIT

## Descrição
Coleção de componentes copy-paste para React com animações suaves usando Tailwind CSS + Motion. Foco em simplicidade: nada de instalação ou config — só copiar e colar.

## Stack
- React + TypeScript
- Tailwind CSS
- Motion (Framer Motion)

## Quando usar
- Prototipagem rápida de componentes animados
- Alternativa mais leve a React Bits
- Quando quer fugir de shadcn e usar Motion direto
