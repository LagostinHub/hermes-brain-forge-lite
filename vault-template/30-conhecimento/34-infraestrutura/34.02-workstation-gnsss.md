# Workstation [DONO] — Config e Otimização

> Estação de trabalho de **vídeo e áudio** para DaVinci Resolve e After Effects. Registro do scan de hardware + todas as otimizações aplicadas em 2026-09-09 (pós-formatação).

## Hardware

| Componente | Detalhe |
|---|---|
| Placa-mãe | BIOSTAR B650MT (AM5 / B650), BIOS 5.35 (09/2024) |
| CPU | AMD Ryzen 5 7600 — 6 núcleos / 12 threads, Zen 4, boost 5.1 GHz, 65W, iGPU Radeon 610M |
| RAM | 32 GB DDR5-6000 CL32 (2x16 GB, EXPO ativo @6000) |
| GPU | NVIDIA GeForce RTX 4060 Ti 16 GB (Ada, compute 8.9), driver 616.92 |
| iGPU | AMD Radeon 610M (integrada) — memória compartilhada, sem VRAM propria |
| Monitor | 3840x2160 @ 59 Hz (4K) |
| Áudio | SSL 2 USB (interface audio pro) + HDMI AMD/NVIDIA + HD Audio |
| Rede | Realtek GbE (desligado) + TP-Link WiFi USB (conectado) |

### Armazenamento
- **C:** SanDisk SSD Plus 1 TB — NVMe M.2 — SO/apps
- **D:** Projects01 — Samsung 860 EVO 500 GB SATA
- **E:** Projects02 — Samsung 860 EVO 500 GB SATA
- **F:** barracuda — Seagate 2 TB HDD (arquivo)

## Otimizações Windows aplicadas

- **Plano de energia**: High Performance (Ultimate falha por config do powercfg)
- **HAGS** (Hardware-accelerated GPU Scheduling): ativo (`HwSchMode=2`)
- **GPU preferida = NVIDIA** para DaVinci Resolve, After Effects e Media Encoder (`GpuPreference=2`)
- **Game Bar / Game DVR**: desligados (política de máquina + usuário)
- **Inicialização limpa**: removidos autostarts de Opera e Edge (mantidos CloudFolder e Painel SSL)

## Debloat (moderado)

- **25 apps removidos**: Clipchamp, Bing News/Weather/Search, Xbox suite + overlays, Teams, Solitaire, Sticky Notes, Todos, Power Automate, YourPhone, Camera, Alarms, Feedback Hub, Sound Recorder, Dev Home, Office Hub, Get Help, Cross Device, Quick Assist, ZuneMusic
- **Servicos desabilitados**: DiagTrack, XblAuthManager, XblGameSave, XboxNetApiSvc, RetailDemo, WMPNetworkSvc, MapsBroker, PcaSvc
- **Telemetria**: `AllowTelemetry=0` + experiencias personalizadas off
- **Apps em 2º plano**: off (`GlobalUserDisabled`)
- **Preservado de propósito**: codecs de video (HEVC/AV1/RAW/MPEG2), Edge, Terminal, Store, CloudFolder, drivers NVIDIA/AMD, Windows Security, .NET

## BIOS (manual — feito 2026-09-09)

- **EXPO**: DDR5-6000 ativo (confirmado via `ConfiguredClockSpeed=6000`)
- **ReBAR + Above 4G**: habilitado (usuario confirmou)
- **SVM / Virtualizacao**: **deixado desligado** (decisao 2026-09-09 — nao afeta Resolve/AE)
- **PBO**: habilitado
- **iGPU**: decisao pendente — desligar se usar so 1 monitor (libera ~512 MB RAM); manter se planeja 2ª tela para paineis

## Proximos passos / upgrade (gargalos)

- **RAM 32 → 64 GB** — maior ganho p/ AE/Resolve 4K
- **CPU 6 nucleos** — teto p/ multi-camadas pesadas (Ryzen 7/9 AM5)
- **NVMe Gen4 dedicado** para cache de render
- Confirmar driver **Studio** (nao Game Ready) no Painel NVIDIA
