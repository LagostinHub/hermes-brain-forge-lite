# Plano Geral — "Brain como cérebro vivo de uma equipe de agentes"

> Plano-mestre consolidado. Fonte de verdade: este vault. Equipe = bots/sessions/subagentes trabalhando specs em paralelo, orquestrados por kanban + OpenSpec, tudo registrado no brain.

## Visão
Vault Obsidian = memória única compartilhada. Skills (mattpocock + openspec + obsidian) = "sistema respiratório" de todo agente/subagente/profile/bot. Hermes gere, OpenCode executa, você aprova.

## Arquitetura da equipe (concorrência)
- 1 gateway (Main Hermes) = gerente sempre-on: kanban → auto_decompose → dispatch (60s).
- Perfis = processos/bots isolados (researcher, builder, qa…), cada um sua state.db.
- Delegação paralela: orchestrator_enabled + max_concurrent_children:10 + subagent_auto_approve.
- OpenCode fatia spec em tasks paralelas (subagent-driven-development).
- Sem colisão: ownership matrix (1 arquivo = 1 agente) + git worktree/branch por change.
- Teto de concorrência (ex.: 4–6 specs simultâneas).
- Limite: escala dentro de 1 máquina (multi-processo), não cluster/cloud.
