## [FERRAMENTA]-Manager (23/07/2026)

### Arquitetura V4 (built-in)
- `[ferramenta]-manager` v4.2.2 instalado via pip como pacote em `venv\Lib\site-packages\[ferramenta]_manager`
- **Não precisa** clonar para `custom_nodes/[FERRAMENTA]-Manager` (já vem embutido como site-package)
- Flag obrigatória: `--enable-manager` (backend ativo, UI v4 nativa do frontend)
- Flag UI clássica: `--enable-manager-legacy-ui` (registra extensões JS legacy em `/extensions/[ferramenta]-manager-legacy/`)

### Estado atual (frontend 1.45.20) — OBSOLETO após workaround
- Frontend 1.45.20 marca `/scripts/ui.js` e extensões legacy como DEPRECATED → botão Manager não renderiza
- Workaround aplicado: usar frontend legacy 1.10.18 baixado manualmente

### Workaround definitivo (24/07/2026)
Frontend 1.10.18 (legacy, suporta extensions legacy) baixado para:
`[CAMINHO]` (extraído de https://github.com/Comfy-Org/[FERRAMENTA]_frontend/releases/download/v1.10.18/dist.zip)

**Como iniciar [FERRAMENTA] com Manager visível:** use `iniciar_[ferramenta]_manager.bat` ou comando:
```powershell
Start-Process -FilePath '[CAMINHO] `
  -ArgumentList 'main.py','--listen','127.0.0.1','--port','8188','--enable-manager-legacy-ui','--front-end-root','[CAMINHO] `
  -WorkingDirectory '[CAMINHO] -WindowStyle Normal
```

Verificado:
- HTML servido é legacy (não Next.js, sem RSC)
- 37 extensões registradas (15 são `[ferramenta]-manager-legacy/*.js`)
- Botão "Manager" aparece na UI

**Para atualizar versões:** renomear `frontend_legacy` e baixar outra release de https://github.com/Comfy-Org/[FERRAMENTA]_frontend/releases, extrair para `frontend_legacy/`.

## Problemas Conhecidos (23/07/2026)

### 🟢 Resolvidos (19:50)
- **[FERRAMENTA]-GPT_SoVITS** — SyntaxError (escape `\\'r\\'`) CORRIGIDO via script Python byte-level replace ✅
- **basicsr, lpips, mmgp, onnx** — pip install na venv ✅
- **iniciar_[ferramenta].bat** — usado `start_fix.bat` temporário com venv python absoluta (iniciar_[ferramenta].bat usa `call venv\Scripts\activate` que falha quando Conda.psm1 tem bug empty Invoke-Expression)

### 🟡 Recorrentes (baseline)
- Database lock crash: `del com\*.db` resolve
- Wan 2.2 14B FP8 pode dar OOM em RTX 4060 Ti 16GB com frames longos
- Após instalar custom nodes, reiniciar [FERRAMENTA] é necessário

### 🧠 Lições (2026-07-23)
- Windows ACE bloqueia `pip.exe` direto → usar `python -m pip install`
- PowerShell escapes complicam edição de strings Python → usar script Python para byte-level replace
- venv do [FERRAMENTA] é Python 3.12.9 diferente do global Program Files — use path absoluto
