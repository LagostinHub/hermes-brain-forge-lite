# MCP Troubleshooting — Problemas Comuns

> Guia rápido de diagnóstico e fix para MCP servers

## Checklist de Diagnóstico

Quando um MCP falha, seguir esta ordem:

1. `hermes mcp test <name>` — testa conectividade real
2. Verificar `%USERPROFILE%\AppData\Local\hermes\logs\` — gateway log
3. Verificar log do próprio servidor (se tiver)
4. Verificar config.yaml — estrutura, paths, env vars
5. Reiniciar app Hermes — MCP só lê config no boot

## Erros Comuns

### WinError 2 — arquivo não encontrado
**Sintoma:** `Connection failed: [WinError 2] The system cannot find the file specified`
**Causa:** path em `command` ou `args` não existe.
**Fix:** localizar o binário correto e atualizar:
```bash
hermes config set mcp_servers.<name>.command "<caminho-correto>"
```

### MSYS Path Pitfall (`/c/` → `C:\c\`)
**Sintoma:** Node ou Python não acha o módulo (`Cannot find module 'C:\c\...'`)
**Causa:** paths MSYS `/c/AI/...` são passados a processos nativos sem tradução.
**Fix:** usar caminhos nativos `C:/AI/...` (forward slash, sem `/c/`).

### Timeout no boot (35s+)
**Sintoma:** `hermes mcp test` retorna `Connection failed: TimeoutError`
**Causa:** servidor demora >30s pra subir (ex: openshorts faz recovery de jobs).
**Fix:** aumentar timeout no config:
```bash
hermes config set mcp_servers.<name>.timeout 60
```

### PYTHONPATH leak (Cause B)
**Sintoma:** `hermes mcp test` ✓ Connected mas tools falham em runtime.
**Causa:** gateway injeta PYTHONPATH do próprio venv no processo filho.
**Fix:** usar o venv do MCP como command e setar PYTHONPATH no env:
```yaml
command: C:/path/to/mcp/venv/Scripts/python.exe
env:
  PYTHONPATH: C:/path/to/mcp/venv/Lib/site-packages
```

### 422 Type Missing Required Argument
**SINTOMA:** `422: 'arguments' is required` ou `Type mismatch`
**Causa:** formato de argumentos errado no tools/call.
**Fix:** consultar schema via `tool_describe` e ajustar params.

### Variáveis de ambiente não resolvidas
**Sintoma:** warning `Config ref '${env:KEY}': KEY is not set`
**Fix:** colocar a key no `.env` correto. Dois paths importam:
- `%USERPROFILE%\.hermes\.env`
- `%USERPROFILE%\AppData\Local\hermes\.env` ← gateway lê primeiro

## Comandos Úteis

```bash
# Listar todos os MCPs com status
hermes mcp list

# Testar um servidor específico
hermes mcp test <name>

# Editar um campo do config (seguro)
hermes config set mcp_servers.<name>.<campo> "<valor>"

# NÃO usar hermes config set com YAML blob (quebra o bloco)
```
