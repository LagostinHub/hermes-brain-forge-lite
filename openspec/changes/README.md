# changes/

Toda mudança nova nasce aqui. Formato: `openspec/changes/<id-kebab>/` com
`proposal.md`, `design.md`, `tasks.md` e `specs/<capability>/spec.md`.

Ciclo: `/openspec-propose` cria aqui → `/openspec-apply-change` implementa →
`/openspec-archive-change` promove para `openspec/specs/` e move a change para
`openspec/changes/archive/`.

Change arquivada é histórico. Não edite uma spec promovida à mão.
